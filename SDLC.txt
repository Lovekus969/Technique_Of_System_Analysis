Agile Development
    Agile Development is an iterative and incremental approach to software development that focuses on flexibility, customer collaboration, and continuous improvement.

Key Characteristics
    Development is done in small iterations
    Frequent feedback from customers
    Welcomes changing requirements
    Working software is delivered early and often

The Unified Process (UP)
    The Unified Process (UP) is a use-case-driven, architecture-centric, and iterative software development framework.

Phases of UP:
    Inception – Define scope and feasibility
    Elaboration – Analyze requirements and design architecture
    Construction – Build the system
    Transition – Deploy and maintain the system

Extreme Programming (XP)
    Extreme Programming (XP) is an Agile methodology that emphasizes high-quality code and customer satisfaction through strict development practices.

Core Practices : 
        Pair programming
        Test-Driven Development (TDD)
        Continuous integration
        Frequent releases
        Simple design
